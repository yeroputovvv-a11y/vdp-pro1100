# VDP PRO 1100

Веб-интерфейс для подготовки переменных данных для Konica Minolta bizhub PRO 1100.

## Текущий этап

Интерфейс принимает PDF-шаблон и Excel со списком номеров. Обработка PDF пока намеренно не включена: сначала фиксируем корректную архитектуру и интерфейс, затем подключаем точную замену текстовых объектов PDF без перерисовки номера.

## План

1. PDF + Excel.
2. Определение/настройка трёх переменных мест.
3. Генерация теста на 3 экземпляра.
4. Проверка размера, шрифта и позиции.
5. Масштабирование до 1000+.
6. Отдельный производственный режим PPML для PRO 1100.
