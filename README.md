# VDP PRO 1100

Веб-интерфейс для подготовки переменных данных для Konica Minolta bizhub PRO 1100.

## Формат Excel

- Строка 1 — названия колонок.
- Строка 2 — эталонные значения. Эти значения используются для поиска переменных объектов в PDF.
- Строки 3+ — данные для печати; одна заполненная строка соответствует одному экземпляру.
- Если в строке есть хотя бы одна ячейка с любым содержимым, включая пробел, строка получает порядковый номер и входит в общий тираж.
- Если в строке после удаления пробелов нет ни одного значения, она считается резервным экземпляром без переменных данных.
- Пустая ячейка конкретного поля означает, что это поле для данного экземпляра не заменяется.

## Что показывает веб-программа

- общий тираж — все пронумерованные строки;
- количество экземпляров с переменными данными — строки, где есть хотя бы одно содержательное значение;
- резерв без данных — строки, которые будут напечатаны, но могут быть заполнены вручную позже;
- список переменных колонок и их эталонов;
- предварительный просмотр данных.

Шаблон Excel скачивается непосредственно из веб-интерфейса и затем загружается обратно уже заполненным.
